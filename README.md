# Calculadora em Python

Calculadora desenvolvida em Python com o objetivo de praticar lógica de programação, estruturas condicionais e estruturas de repetição.

## 📌 Sobre o projeto

Este projeto consiste em uma calculadora executada pelo terminal, permitindo ao usuário realizar operações matemáticas básicas e escolher diferentes opções por meio de um menu interativo.

O projeto foi desenvolvido como parte dos meus estudos em Python e tem como foco a prática dos principais conceitos de programação.

## ⚙️ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🔢 Alteração dos números utilizados nos cálculos
- ⚠️ Tratamento de divisão por zero
- ❌ Validação de opções inválidas
- 🚪 Opção para encerrar o programa

## 💻 Tecnologias utilizadas

- **Python 3**

## 🧠 Conceitos praticados

- Variáveis
- Entrada de dados com `input()`
- Conversão de dados com `int()`
- Estruturas condicionais (`if`, `elif` e `else`)
- Estrutura de repetição `while`
- Operadores matemáticos
- F-strings
- Validação de dados
